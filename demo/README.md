# Banking System REST API

## 📌 Project Overview
This project is a Banking System developed using Spring Boot. It provides REST APIs for managing accounts and transferring funds.

## 🚀 Features
- Create Account
- View Account Details
- Transfer Funds Between Accounts

## 🛠️ Tech Stack
- Java
- Spring Boot
- MySQL
- JPA (Hibernate)

## 🔗 API Endpoints

### Create Account
POST /api/account

### Get Account
GET /api/account/{id}

### Transfer Money
POST /api/transfer?from=1&to=2&amount=100
